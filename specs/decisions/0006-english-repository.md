# ADR-0006: English for everything in the repository

- Status: accepted
- Date: 2026-11-07

## Context

The repository is public. MCP tool descriptions are read by models, and the docs are read by contributors who may not speak Portuguese.

## Decision

Code, specs, docs, commit messages and MCP tool descriptions are written in English.

## Alternatives rejected

- Code in English and docs in Portuguese, as in other projects by the same author. It would exclude most potential contributors, and tool descriptions would still have to be in English.

## Consequences

- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/), in English.
